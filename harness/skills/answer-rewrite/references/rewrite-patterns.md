# Rewrite Patterns

## Common Issues and Fixes

### 1. Overly Academic Language
**Problem:** "The implementation leverages a multi-tier architecture paradigm..."
**Fix (Spoken):** "We use a layered architecture — let me walk you through each layer."

### 2. Missing Structure
**Problem:** Rambling without clear opening/closing
**Fix:** Add a preview sentence at the start and a summary at the end.

### 3. Too Short / Lacks Depth
**Problem:** "It uses context window management to handle long conversations."
**Fix:** Expand with specific techniques: sliding window, summarization, tiered budgeting.

### 4. Too Long / Repetitive
**Problem:** Saying the same thing three different ways
**Fix:** Keep the strongest version, remove the others.

### 5. No Concrete Examples
**Problem:** Abstract statements without evidence
**Fix:** Add a specific scenario: "For example, when we built..."

### 6. Passive Voice
**Problem:** "The system was designed to handle errors"
**Fix (Spoken):** "We designed the system to handle errors"

## Format

### Spoken Version Style
- Use contractions and natural pauses
- Start with a brief hook
- Include verbal signposts: "First...", "The key insight is..."
- End with a confident conclusion
- Keep sentences short for easy delivery

### Formal Version Style
- Complete sentences, proper grammar
- Technical precision
- Well-structured paragraphs
- Professional tone
- Suitable for written submission or documentation
