# Followup Patterns

## Common Interviewer Follow-up Types

### Depth Probe
After a surface-level answer, the interviewer digs deeper:
- "Can you elaborate on the trade-offs?"
- "What was the hardest part of implementing that?"
- "How would this scale to 10x the load?"

### Contradiction Test
The interviewer presents a counter-argument:
- "But doesn't that approach cause latency issues?"
- "Some engineers argue the opposite. What would you say?"

### Real-World Scenario
The interviewer presents a concrete problem:
- "If you encountered this bug in production at 3am, what would you do?"
- "How would you explain this to a non-technical stakeholder?"

### Comparison
Asking to compare with alternatives:
- "How does this compare to using LangChain?"
- "Why not use a vector database instead?"

### Failure Mode
Exploring what could go wrong:
- "What are the failure modes of this approach?"
- "When would you NOT use this technique?"

## Answer Strategy Template

For each follow-up question, provide:

1. **Why asked**: The interviewer's intent
2. **Strategy**: How to structure the response
3. **Key points**: Must-mention items
4. **Pitfalls**: What to avoid saying
