# OfferPilot v3

状态：已归档的过渡版本，没有独立、稳定的产品契约。

## 定位

v3 主要用于把 v2 的数据库和运行时继续收敛，而不是发布新的用户功能集合。该阶段形成的能力随后直接合并进 v4。

## 主要演进

- 收紧 Approval 决策幂等与一次性副作用执行。
- 完善取消竞争、重启中断、数据库锁和音频清理行为。
- 将 Provider Usage、首 Token、结构化输出校验和阶段耗时纳入运行事件。
- 按业务域整理后端包边界，移除旧 Trace、Checkpoint 和兼容入口。
- 为 v4 的精简 Schema、26 条公开路径和当前前端契约提供迁移基础。

由于该阶段没有独立稳定接口，不应从本目录推导 API 或 Schema。当前实现请阅读 [v4](../v4/README.md)。
